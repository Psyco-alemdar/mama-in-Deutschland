MODULE 02

Prompt Engineering essentiel

Apprendre une structure simple qui fonctionne dans la majorité des cas.

Leçon 2.1

La structure en 6 blocs

Un prompt professionnel peut être construit avec six blocs : objectif, contexte, données, contraintes, format et critères de qualité. Tous ne sont pas toujours nécessaires, mais cette structure permet d’éviter les demandes floues.

Prompt prêt à utiliser
Objectif : [ce que je veux obtenir]
Contexte : [pour qui / pourquoi]
Données : [informations à utiliser]
Contraintes : [ce qu’il faut respecter]
Format : [tableau, email, plan, etc.]
Critères de qualité : [ce qui rendra la réponse bonne]
Leçon 2.2

Rôle et expertise

Attribuer un rôle peut aider lorsque la tâche dépend d’une perspective professionnelle précise. Exemple : analyste marketing, recruteur, chef de projet. Mais un rôle vague comme “sois un expert” n’améliore pas toujours le résultat.

Exercice

Prends un prompt sans rôle. Ajoute ensuite un rôle réellement pertinent et compare ce qui change.

Leçon 2.3

Contraintes utiles

Les contraintes permettent de guider la sortie : longueur, niveau de langage, éléments obligatoires, éléments interdits, langue, nombre d’options, ton ou format.

Prompt prêt à utiliser
Rédige une réponse de 180 mots maximum, en français simple, avec 3 recommandations concrètes, sans jargon et sans promesse excessive.
Leçon 2.4

Formats de sortie

Demander un format précis transforme une réponse générale en livrable utilisable : tableau, checklist, email, plan, JSON, script ou procédure.

Prompt prêt à utiliser
Présente ta réponse sous forme de tableau avec 4 colonnes : problème, cause probable, action recommandée, priorité.
