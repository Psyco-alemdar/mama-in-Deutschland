MODULE 07

Agents IA

Comprendre quand un agent est utile et comment éviter la complexité inutile.

Leçon 7.1

Qu’est-ce qu’un agent ?

Un agent reçoit un objectif, sélectionne ou utilise des outils, garde parfois un état et exécute plusieurs étapes pour atteindre un résultat.

Leçon 7.2

Architecture minimale

Objectif → plan → outils → exécution → vérification → résultat. Cette architecture simple couvre une grande partie des cas utiles.

Leçon 7.3

Quand ne pas utiliser un agent

Si une tâche est linéaire et prévisible, un workflow classique est souvent meilleur : moins coûteux, plus rapide et plus facile à contrôler.

Leçon 7.4

Sécurité et limites

Définis clairement les permissions, les données accessibles, les actions interdites et les étapes nécessitant confirmation.

Exercice

Dessine l’architecture d’un agent simple pour une tâche professionnelle. Ajoute au moins 3 garde-fous.
